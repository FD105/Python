# miniPython

Dieses Repo beinhaltet stand jetzt folgende kleine Projekte:

einen Passwortgenerator
einen groben Taschenrechner
einen kurz gefassten Ansatz für Machine-Learningund 
einen Morsecode-De- und -Encoder.

Diese Projekte sind recht kurz gehalten und stellen eher einen kleinen Zeitvertreib dar. Manche lassen sich bestimmt noch um einiges erweitern oder verbessern.
Soweit ich diese Programme getestet habe, sind mir keine Fehler aufgefallen. Es können jedoch Irrtümer bei der Implementierung von Funktionen aufgetreten sein.
